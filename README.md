# template_java25
Minimal mall för framtida Spring Boot‑projekt med Java 25 LTS.

Det här repot är en ren grundmall som kan kopieras inför varje nytt projekt.
Allt är förkonfigurerat så att du slipper skapa nya Spring Boot‑projekt från scratch.

## 🚀 Funktioner
* Java 25 LTS
* Spring Boot 4.x
* Spring MVC (REST API)
* Swagger UI / OpenAPI  
  → tillgänglig på /swagger-ui.html
* H2 in‑memory databas
* JPA / Hibernate
* Teststöd (JUnit, Mockito, Spring Test)
